# Agentic AI Protocols (MCP, A2A, ACP)

Workbook for the Agentic AI Protocols course on Coursera. Analyze MCP architecture, design A2A task coordination, and create multi-protocol implementation plans spanning MCP, Agent-to-Agent (A2A), and Agent Communication Protocol (ACP).

## Modules

| Module | Topic | Key Files |
|--------|-------|-----------|
| 1 | Analyze MCP Architecture | Task text files, architecture analysis PDF |
| 2 | Design A2A Task Coordination | Task text files, A2A coordination PDF |
| 3 | Multi-Protocol Implementation Plans | Task text files, implementation plan PDFs |

## Prerequisites

No code dependencies — this is a text and exercise-based course.

## Setup

No setup required. All exercises are text-based analysis and design tasks.

## Running

No runnable code. Complete the exercises by editing the task text files and submitting through Coursera.

## Tests

No automated tests. Exercises are validated through Coursera submission.

## Additional Resources

- Module 1 analyzes MCP architecture for given scenarios
- Module 2 designs A2A task coordination for multi-agent scenarios
- Module 3 creates multi-protocol (MCP + A2A + ACP) implementation plans
