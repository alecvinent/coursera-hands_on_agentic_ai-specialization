# Ethical Governance & Risk in Agentic AI

Workbook for the Ethical Governance & Risk in Agentic AI course on Coursera. Assess AI autonomy levels, build multi-jurisdictional compliance strategies, and design governance frameworks for healthcare and domain-specific AI systems.

## Modules

| Module | Topic | Key Files |
|--------|-------|-----------|
| 1 | Assess AI Autonomy Levels | Task text files, autonomy assessment PDF |
| 2 | Multi-Jurisdictional AI Compliance Strategy | Task text files, compliance strategy PDF |
| 3 | Healthcare & Domain-Specific Governance | Task text files, governance framework documents |

## Prerequisites

No code dependencies — this is a text and exercise-based course.

## Setup

No setup required. All exercises are text-based analysis and design tasks.

## Running

No runnable code. Complete the exercises by editing the task text files and submitting through Coursera.

## Tests

No automated tests. Exercises are validated through Coursera submission.

## Additional Resources

- Module 1 assesses AI autonomy levels in organizations
- Module 2 builds multi-jurisdictional AI compliance strategies
- Module 3 covers healthcare AI governance frameworks and domain-specific exercises (residential, restaurant, bistro)
