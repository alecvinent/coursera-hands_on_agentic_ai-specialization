# Advanced Multi-Agent AI Systems

Workbook for the Advanced Multi-Agent AI Systems course on Coursera. Design multi-agent system architectures, implement governance frameworks, and build system prototypes with design portfolios.

## Modules

| Module | Topic | Key Files |
|--------|-------|-----------|
| 1 | Design Multi-Agent System Architecture | Task text files, architecture PDF |
| 2 | Implement Governance Framework | Task text files, governance PDF |
| 3 | Build Prototype & Design Portfolio | `task1/agent.py`, `task2/agent.py` |

## Prerequisites

- Python 3.10+
- [Poetry](https://python-poetry.org/)

## Setup

```bash
poetry install
```

## Running

```bash
# Module 3 — Multi-Agent Prototype
cd src/advanced-multi-agent-ai-system-course/module_3/task1 && python agent.py
cd src/advanced-multi-agent-ai-system-course/module_3/task2 && python agent.py
```

## Tests

No automated test suite. Exercises are validated through Coursera submission.

## Additional Resources

- Modules 1-2 are text-based (architecture design and governance framework exercises)
- Module 3 includes a multi-agent system prototype and a system design portfolio
