Which agent type was easiest to identify? Why?  

Reactive agents are typically the easiest to identify.

They rely on simple stimulus-response mechanisms (such as `IF condition THEN action` rules) without needing memory of
past states, internal models, or long-term planning capabilities. When an application instantly triggers an output as
soon as a single sensor threshold is breached—such as an emergency brake triggering upon detecting an obstacle—it
clear-cut displays a reactive architecture.
